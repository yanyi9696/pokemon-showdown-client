# Rogue dialogue portraits

Generated with the built-in image_gen tool on 2026-10-19 for the requested dialogue presentation. Each transparent PNG has two equal square cells: neutral on the left, approval on the right. Grunts use an embarrassed acknowledgement instead of a smile. CSS selects the cell without copying or repainting image pixels.

Companion trainers reuse their existing paired assets in `../rogue-companions/`. The registry in `client-fantasy-rogue.js` includes only available images. Brock, Mewtwo and Maxie generation was rejected by the image service; they retain their native single-image presentation with the same entrance animation. No independent second expression is claimed for those three.

Prompt and output provenance: `generation.json`. Generated artwork is a project illustration based on the named Pokémon characters; it is not official artwork.
